The finding

We proved in Lean 4 the discrete mathematics that turns a protein into a Karnaugh map: 131 machine-checked theorems, none left unproved. The proofs guard a real pipeline against a bug it once had, refused a claim we got wrong, and show which experiments can test the encoding at all.

Gray-coded grids of sequences, from Petoukhov's genetic Karnaugh matrices to chaos-game maps (FCGR), are usually taken on trust. Here each step is a checked theorem, and every claim says how it is known.

A code that changes one bit at a time

Binary counting can flip many bits at once: 0111 → 1000 flips four. The reflected Gray code g(n) = n ⊕ (n ≫ 1) visits every number once and changes exactly one bit per step. DNA needs two bits, and A C G T is itself a Gray cycle.

A Karnaugh map is a folded truth table

Order a grid's rows and columns by the Gray code and touching cells differ in one variable, even across the edges, which wrap like a torus. Put a k-mer's first letters on the rows and the rest on the columns: each 2-mer owns one cell of a 4×4 map, each 4-mer one of a 16×16 map.

Twenty amino acids on a five-dimensional cube

Proteins need five bits: 32 codewords for 20 residues. Numbering residues group by group before Gray-coding keeps chemistry close. All 190 pairwise distances are proved: 40 pairs sit one bit apart, only four sit five apart, and the code uses exactly half of the cube's 80 edges.

Contacts as a Boolean function

A contact map is a Boolean function: C(i,j) = 1 when residues i and j lie within 8 Å. Quine–McCluskey merges 1-cells one bit apart into ever larger cubes; the cubes that cannot grow, the prime implicants, describe the map most briefly. For an 8-residue example Lean proves the map symmetric, and that no two of its contacts can merge.

⊢contactMap8_symmetric⊢contactMap_no_groupable_minterms⊢cc_cover_complete

How Lean checks a claim

In Lean 4 a statement is a type and a proof is a program that a small kernel checks. For finite claims, native_decide evaluates the statement on every case in compiled code, up to 220 cases in one theorem. The price is stated: those proofs also trust Lean's compiler. No proof uses sorry; none adds an axiom of its own.

-- Gray code is additive over GF(2)
theorem sc_gray_gf2_linear :
  ∀ x y : Fin 32,
    scGray (x.val ^^^ y.val)
      = scGray x.val ^^^ scGray y.val
  := by native_decide

What the proofs bought

A silent bug, now ruled out

Our co-evolution pipeline once fed 400-cell (20×20) maps to an 8-bit minimiser with 256 addresses. Cells 256–399 wrapped onto 0–143, and 143 of 152 "essential" rules were phantoms. Maps are now padded to 32×32, and a theorem guarantees rules on real residues fire only inside the 20×20 block.

⊢cc_padding_safety◆143 / 152 phantom

A claim we got wrong, refused

A draft said Gray-coded positions break chain segments apart, so plain binary was required. Lean would not accept the proof. What is true: a cube is an unbroken segment under either numbering, merely relabelled.

⊢sc_gray_cube_is_also_interval⊢sc_gray_relabels_segments

Which experiments can see the encoding

Since g(x ⊕ y) = g(x) ⊕ g(y), a Gray-ordered map is a lexicographic (FCGR) map with its cells permuted: every distance-based statistic is identical. Only Hamming distance tells them apart. Native contacts are one bit apart 1.18× more often than background, but only 2.5 s.d. above random code assignments.

What it means for protein structure

With plain position bits, a prime implicant of a contact map is a block: every residue of one chain segment touches every residue of another. That is the Boolean signature of a β-ladder or a helix packing, and real proteins are full of it.

⊢sc_contact_cube_is_block◆150 proteins, 86× shuffles, p = 10⁻²⁵

What such circuits cannot do: a predictor that sees only (residue i, residue j, separation) cannot rank two pairs that land in the same cell, so its precision is capped by how pure the cells are.

In short

  • Every step from sequence to Karnaugh map to minimised circuit is a checked theorem: 131 in Lean 4, with the trust each one needs stated.
  • The proofs paid off in practice: a padding guarantee, a refuted claim, and a clear rule for which tests can see a Gray code.
  • Minimised contact maps recover secondary-structure blocks, but sequence-only circuits cannot fold a protein; the missing information has to come from coupling or dynamics.
